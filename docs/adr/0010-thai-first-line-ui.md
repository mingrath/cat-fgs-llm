# Thai-first LINE UI

Status: accepted

The LINE OA prototype will use Thai-first caregiver-facing language. Score interpretation, warnings, retake guidance, symptom checks, and veterinary-assessment guidance should be written in natural Thai, while internal research labels, model metrics, configs, and logs may remain English.

## Considered Options

- **Thai-first UI**: chosen because the target caregivers are Thai LINE users and safety guidance must be easy to understand.
- **English-first UI**: rejected because it does not match the target environment.
- **Bilingual UI**: deferred because it adds wording and UI complexity before the prototype proves the core flow.

## Consequences

Thai copy is part of the safety surface, not cosmetic translation. The prototype should avoid awkward literal translations and should keep medical claims cautious.
