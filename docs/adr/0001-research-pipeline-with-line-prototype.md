# Research pipeline with LINE OA prototype

Status: accepted

We will build a research-grade model pipeline with a LINE Official Account prototype as deployment proof, not a real user-facing medical product. This keeps the project focused on credible labels, model evaluation, calibration, abstention, and Thai caregiver workflow evidence while avoiding unsupported clinical-product claims, liability, and production safety obligations.

## Considered Options

- **Research-grade model pipeline + LINE OA prototype**: chosen because it proves deployability without pretending to be a validated medical device.
- **Real user-facing product**: rejected for this phase because it would require clinical validation, safety monitoring, Thai medical copy review, vet escalation operations, and liability controls beyond current project evidence.
